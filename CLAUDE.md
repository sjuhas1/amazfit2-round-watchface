# CLAUDE.md

Zepp OS (API v1) analog watch face "Dual Rings Analog" for the Amazfit Active 2 Round (466×466, `Milan*` platforms). See README.md for the user-facing overview.

## Commands

- `. ./env.sh`: run first in each shell. It puts `.tools/bin` (local npm, since this machine has no system npm) and `node_modules/.bin` on PATH.
- `npm run assets`: regenerates `assets/466x466-active-2/**`, `preview.png` and `store/preview-360.png`. The output is deterministic, so a clean `git status` afterwards means nothing changed visually.
- `npm run build`: regenerates the assets, then runs `zeus build`, which writes `dist/*.zab`.
- `npm run preview` / `npx zeus dev`: need `zeus login` and a phone or simulator. Don't run them unattended, because they are interactive.

There are no tests or linter. Verify a change by running `npm run assets` and then looking at `preview.png`, which is a composite of the normal-mode face.

## Architecture

- `watchface/layout.js` is the single source of truth for geometry. Both `watchface/index.js` (on the watch, via `import`) and `tools/gen-assets.cjs` (on the PC, via `require`) use it, so it must stay CommonJS with plain-data exports and no Node or Zepp APIs.
- All PNGs are generated from SVG strings in `tools/gen-assets.cjs` using sharp. Never hand-edit files in `assets/`. Change the generator and regenerate. The generated assets are committed on purpose.
- Colours live in two places: the `COL` object in `gen-assets.cjs` (baked into images) and `BATTERY_COLOR` / `STEPS_COLOR` in `index.js` (the live `ARC_PROGRESS` rings). Keep them in sync.
- The AOD variant is generated by the same functions with `aod: true` into `assets/.../aod/`, and drawn with `show_level: ONAL_AOD`.
- The text renders in the Lato font. If Lato isn't installed, sharp silently falls back to another font, so check `fc-list | grep -i lato` when the numerals look off.

## Zepp OS gotchas

- `hmUI.show_level.ONAL_AOD` and `hightCost` in `app.json` are the real API spellings. Don't "fix" them.
- Rings are full-circle `ARC_PROGRESS` widgets updated only via `prop.LEVEL`. Updating them with a partial `prop.MORE` made the rings vanish on the real watch, though the simulator looked fine.
- Sensor listeners are attached in `WIDGET_DELEGATE.resume_call` and removed in `pause_call`. Keep this pattern for any new sensor.
- `app.json` `appId` 1136672 is registered to the owner's Zepp developer account. Don't change it.
- The version lives in two places: `app.json` (`version.code`, an integer that must increase with every store upload, and `version.name`) and `package.json` `version`. Bump them together.
- Zepp store rules require `i18n` entries for `en-US`, `zh-CN` and `zh-TW`. Keep all three when renaming the face.
- The weather `IMG_LEVEL` expects exactly 29 icons (`weather/0..28.png`), indexed by Zepp's weather code.
